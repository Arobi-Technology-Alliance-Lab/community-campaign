# Security

If you believe you have found a security vulnerability in an Arobi product or service, please report it privately
through [aura-genesis.org/security](https://aura-genesis.org/security). Do not open a public issue, post it in a community,
or access data that is not yours.

Please test only within written scope, give us reasonable time to fix what you find before you disclose it, and include
enough detail for us to reproduce it. We appreciate responsible research.

This repository holds no code or secrets; reports about it are welcome through the same route.
