# Assets

All artwork here is Arobi's own, drawn in the Arobi element-chart style: an ink tile with a ring, the symbol in the Hue
spectrum, the name in muted capitals, and the four-band stripe.

This folder holds finished pictures only. The drawings they are made from are not published: a vector or layered
master can be re-used at any size and re-coloured in seconds, so the masters stay private. Every picture carries, inside
the file, the text that says whose it is.

| File | What it is |
|---|---|
| `campaign-board.png` | 16:9 board: the three pillars as elements on the Trust + Assurance foundation, with the elements we ship |
| `social-preview.png` | 1280 x 640 card for link previews |
| `pillar-superintelligence.png` | Pillar I: **Si**, Superintelligence |
| `pillar-abundance.png` | Pillar II: **Ab**, Abundance |
| `pillar-success.png` | Pillar III: **Su**, Success |
| `foundation-trust-assurance.png` | The foundation under all three |
| `hue-full.png`, `ullumii-desktop-full.png`, `jaws-browser-full.png` | Elements 1 to 3: Hue (Computer), Ul (Desktop), Jw (Browser) |

Pillar numbers are Roman (I, II, III) so they never collide with the product elements' numbers (1, 2, 3, and the next
free number for each new product).

## Before changing anything here

```bash
node scripts/check-assets.mjs
```

It fails if a vector or layered master is present anywhere in the repository (SVG, AI, EPS, PDF, PSD, Figma and
similar), or if a PNG does not name its owner in its own Copyright text.
