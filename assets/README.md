# Assets

All artwork here is Arobi's own, drawn in the Arobi element-chart style: a 172 px ink tile with a 2 px ring, the
symbol in the Hue spectrum (`#ff2d95 #ff7a3d #ffe34d #5cff7a #2de2ff #8a6bff`), the name in muted capitals, and the
four-band stripe (`#ff2d95 #ffe34d #2de2ff #5cff7a`). Text is outlined, so no font is needed to show any SVG, and no file
links to anything outside itself.

| File | What it is |
|---|---|
| `campaign-board.svg` / `.png` | 16:9 board: the three pillars as elements on the Trust + Assurance foundation, with the elements we ship |
| `social-preview.svg` / `.png` | 1280 x 640 card for link previews |
| `pillar-superintelligence.*` | Pillar I: **Si**, Superintelligence |
| `pillar-abundance.*` | Pillar II: **Ab**, Abundance |
| `pillar-success.*` | Pillar III: **Su**, Success |
| `foundation-trust-assurance.*` | The foundation under all three |
| `hue-full.svg`, `ullumii-desktop-full.svg`, `jaws-browser-full.svg` | Elements 1 to 3: Hue (Computer), Ul (Desktop), Jw (Browser) |

Pillar numbers are Roman (I, II, III) so they never collide with the product elements' numbers (1, 2, 3, and the next
free number for each new product).
